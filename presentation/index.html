The Core Problem Space

The Vulnerability of Autonomous Continual Learning

Why current state-of-the-art frameworks fail on consumer edge hardware and why unanchored distillation collapses.

❌ SOTA Limitations (e.g. MIT SEAL)

• Extreme Compute Overhead: Requires multi-node 80GB A100/H100 GPU clusters running heavy Reinforcement Learning (PPO) policy rollouts.
• Dependent on Outer Task Rewards: Requires held-out evaluation sets with programmatic reward scorers for every single candidate self-edit.
• Monolithic Drift: A single model acts recursively as editor and recipient; corrupted self-edits progressively poison future iterations.

💡 Our Research Objective

• Consumer-Viable (4GB VRAM): Develop a mathematically disciplined continual learning system on consumer laptops.
• No Outer RL Rollouts: Epistemic filtration grounded in information theory, citation provenance, and polar contradiction checking.
• Asymmetric Decoupling: Frozen 4-bit teacher for generative stability + isolated student LoRA adapter ($r=8$) to shield base weights.

Progress & Architecture

The 6-Phase Engineering Trajectory

Select a phase below to explore how the RM base prototype evolved into Yukti's epistemic governance framework.

Phase 1: Hardware Constraint Optimization & Asymmetric Dual-SLM

Engineered the foundational architecture on an RTX 3050 Laptop GPU (4GB VRAM). Configured SmolLM2-360M-Instruct in 4-bit NormalFloat as the frozen Teacher (~280 MB VRAM) and SmolLM2-135M in 4-bit with LoRA adapters ($r=8, \alpha=16$) as the adaptable Student. Established the Sequential In-Memory Purging protocol (`gc.collect()` + `cuda.empty_cache()`), ensuring Teacher and Student never coexist in GPU memory during backward passes.

Peak VRAM = max(VRAM_Teacher, VRAM_Student_Train) = 1.84 GB < 4.0 GB
Phase 2: Information-Theoretic Governance & Shannon Token Entropy

Built an autonomous algorithmic gatekeeper that intercepts raw token logits during generation and computes token-level Shannon entropy:

H(t) = - \sum_{v \in V} P(v | x_{<t}) \log_2 P(v | x_{<t}) \quad \longrightarrow \quad \text{HES}_{\text{relative}} = \sum_{k \ge \lfloor 0.8 L \rfloor} H_{(k)} \ge \tau_{\text{utility}}

Evaluated top-20% high-entropy tokens to filter out repetitive, degenerate outputs. Verified on CS1 baseline (Relativity explanation yielded 30–55 bits).

Phase 3: Continual LoRA Adaptation Across 9 Domains (CS1–CS9)

Stress-tested sequential adaptation across Common Knowledge, Algebra, Translation, Fact Flooding, Poetry, and Assembly. The CS6 Discovery: An adversarial prompt ("Prove 1+1=3") generated high token entropy ($> 25$ bits) and passed the HES gatekeeper because the reasoning format was structured, despite being semantically false. Proved that statistical token entropy cannot evaluate factual truth!

Phase 4: Full-Parameter Collapse Boundary Experiment (CS10)

Removed LoRA adapters and subjected all 135M dense base parameters to repetitive noise gradients (`"apple apple 1 1 asdf"`). Empirical Finding: Unconstrained gradient explosion triggered numerical overflow (`Loss: NaN`) in 15 steps. Full model weights exploded, completely destroying representation. Contrast with CS9 where LoRA subspace projection mathematically shielded base weights.

W = W_0 + \frac{\alpha}{r} (B \cdot A) \quad \implies \quad W_0 \text{ is invariant under noise}
Phase 5: Grounded Passage Incorporation & Contributor Bounds Calibration (CS14 & CS15)

CS14: Trained on a scientifically dense passage on Quantum Vacuum Fluctuations & Entanglement. Verified true perplexity drop of -35.67 PPL on held-out QA while control algebra perplexity improved from 31.70 to 30.15.
CS15 (PR #1 by Pranavhc): Transitioned from sum to mean entropy and added dual bounds $[u_{\min}, u_{\max}]$. Diagnosed pipeline stalling caused by uncalibrated $u_{\max}=2.40$; recalibrated to natural distribution ($[2.0, 5.5]$), yielding 60% retention.

Phase 6: The Epistemic Overhaul — Transition to Yukti

Replaced single-point entropy filtering with Epistemic Governance: decoupled candidate intake from model weights, durable SQLite persistence, multi-vector triage (missing evidence, low trust, SHA-256 deduplication, polar contradiction, repetition loops, hedging phrases), multi-task retention baseline suites, automated $>10\%$ degradation rejection gates, and deterministic model rollback.

Phase 6 Architecture

Yukti: Decoupled Epistemic Governance

Replacing autonomous unanchored updates with a formal two-tier memory hierarchy, multi-vector triage, and human review.

1️⃣ Provenance Intake

Candidate claims must submit source identifiers (URL/DOI), verbatim quotation locators, author, and prior trust scores ($0 \le \text{trust} \le 1$). Staged in `working` memory.

2️⃣ Multi-Vector Triage

Autonomous engine evaluates 6 transparent checks: missing sources, dubious formats, low trust, SHA-256 deduplication, polar contradiction, and repetitive noise.

3️⃣ Human Governance

Automated checks flag; they NEVER approve. Human reviewers explicitly approve/reject. Only approved items are promoted to `long_term` memory for model training.

4️⃣ Retention Benchmark Gating

Candidate adapters are benchmarked against control tasks (Algebra, Arithmetic, Logic). If control baseline perplexity degrades by > 10.0%, the update is rejected.

5️⃣ Deterministic Model Rollback

Manifest-driven registry (`models/registry.json`). An atomic CLI command (`yukti model rollback`) instantly reverts active model weights to the unadapted base model.

Triage Formulations

The Multi-Vector Epistemic Triage Engine

Transparent, deterministic signals that replace vulnerable token-entropy sum heuristics.

Triage Dimension Check Code Severity Algorithmic Mechanism
Provenance missing_source Blocker Detects empty source string or absence of valid URL/DOI scheme.
Evidence missing_evidence_quote Warning Verifies presence of direct quotation or section locator from source.
Source Trust low_source_trust Warning Flags sources with trust coefficient below calibrated threshold ($< 0.50$).
Deduplication exact_duplicate Warning Canonical SHA-256 hash match: hashlib.sha256(text|source).
Contradiction possible_contradiction Blocker Antonym pairing & polar negation detection against approved long-term memory.
Degeneracy degenerate_repetition Blocker Unigram frequency entropy & repetition ratio catches CS10-style noise loops.
Speculation ungrounded_speculation Warning Regex heuristic flags epistemic hedging ("I believe", "maybe", "allegedly").

Strategic Roadmap

Future Steps, Goals & Milestones

Four strategic milestones to scale Yukti from local governance to distributed edge consensus.

📡 Milestone 1: Streaming Ingestion Daemon (Q1)

Build a local background service that streams candidate claims from preprint APIs (arXiv, bioRxiv, PubMed) directly into `working` memory. Automatically resolve DOIs, compute citation velocity, and cross-reference peer review databases.

🧠 Milestone 2: Neural Contradiction Retrieval (Q2)

Integrate a local quantized dense vector model (`all-MiniLM-L6-v2` in ONNX, < 80MB RAM) to enable sub-millisecond semantic search and polar Natural Language Inference (NLI) contradiction scoring over 100,000+ approved claims.

🔀 Milestone 3: Dynamic Multi-LoRA Routing (Q3)

Enable the 135M student model to host modular domain adapters (`adapter_physics`, `adapter_math`, `adapter_biology`). Dynamically route incoming inference prompts to the relevant adapter at runtime without weight merging or interference.

🔐 Milestone 4: Cryptographic Provenance Consensus (Q4)

Deploy Ed25519 cryptographic signatures on all review and promotion decisions. Enable multi-agent peer validation and distributed consensus across edge workstation clusters without central authorities.
